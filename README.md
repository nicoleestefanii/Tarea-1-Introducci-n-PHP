# Laboratorio - Introducción a PHP

## Descripción del laboratorio

Este laboratorio contiene una serie de ejercicios prácticos realizados como introducción al lenguaje PHP. A través de los diferentes problemas se practican conceptos básicos de programación como el uso de variables, operaciones matemáticas, entrada de datos, procesamiento de información y estructuras utilizadas para desarrollar páginas web dinámicas.

Los ejercicios también muestran la relación entre HTML y PHP, especialmente mediante formularios que permiten ingresar información y enviarla a otros archivos PHP para ser procesada. El laboratorio fue desarrollado utilizando Visual Studio Code y un servidor local para ejecutar los archivos PHP.
